Your Stream
Native Detection
The C++20 daemon polls native OS APIs (WinRT SMTC on Windows, libdbus-1 MPRIS on Linux) with track-change artwork caching so identical tracks cause zero unnecessary reads.
Atomic JSON & Text Exports
Updates current_song.json and Snaz-style .txt files (Time, Date, Countdown, Chronos, System Info, Textline, Twitch) only when values change.
Headless UI Separation
Configure everything in a modern Dear ImGui window, then close it into Headless Mode to free 100% of GUI memory while the ~4.5 MB daemon stays active in your tray.
Features

Everything You Need

Now Playing, Discord Rich Presence, and full Snaz-inspired overlays in one fast binary.

C++20 Ultra-Low RAM
Rewritten from scratch in native C++20. The Windows daemon runs in ~4.5–6 MB private RAM with delay-loaded DirectX, and Linux separates daemon and GUI binaries completely.
Album Artwork & Exports
Full-resolution cover art for OBS plus optional Snaz exports (TrackArtist.txt, TrackSong.txt, TrackAlbum.txt, PlayingNow.txt, and track-info.json).
Discord RPC Listening
Native C++ Discord IPC displaying a Listening activity (type: 2) with iTunes artwork lookup, album metadata, and status badges.
Dynamic Color
Optional Adaptive UI: the OBS Browser widget extracts dominant colors from your album art and blends smoothly with every track.
Audio Visualizer
Integrated animated visualizer bars above the OBS widget with matching hue transitions and zero CPU overhead when hidden.
Time, Date & Timers
Live Time.txt, localized Date.txt, target-date Countdown, Chrono Down, and Chrono Up with Start/Pause/Reset.
System Info
Native CPU %, RAM usage/available, running process count, and upload/download rates sampled directly from Windows APIs or Linux /proc.
Textline & Dynamic Files
Rotate custom messages automatically and fetch remote HTTP/HTTPS text or image URLs on a dedicated background thread.
Twitch Helix & Zero Bloat
Export live viewer counts, search categories, and update your stream title/game. Single standalone binary on Windows, native packages on Linux.
